### Issue: Fix Integration Test Workflow Failures

The integration test workflow is currently failing due to Docker port conflicts and Go module cache errors. To address these issues, the following steps should be added to the integration test workflow:

1. **Stop and Remove Containers using Port 6379**  
   Before running the integration tests, we need to ensure that no containers are using port 6379 to avoid conflicts. Add the following step:
   ```yaml
   - name: Stop and remove any containers using port 6379
     run: |
       if [ $(docker ps -q --filter "ancestor=redis") ]; then
         docker stop $(docker ps -q --filter "ancestor=redis");
         docker rm $(docker ps -aq --filter "ancestor=redis");
       fi
   ```

2. **Clean Go Module Cache**  
   To prevent errors related to the Go module cache, we should clean the cache before restoring it. Add this step before the cache restore step:
   ```yaml
   - name: Clean Go module cache
     run: go clean -modcache
   ```

Implementing these changes should help resolve the integration test workflow failures.
